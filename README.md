# ics-paper-hub 🖨️📱🤖

> **"Leaving the Screen, Staying in the Loop."**  
> 异步物理人机交互中枢（Human-in-the-Physical-Loop AI Hub）。  
> 让 AI 能够将带有结构化元数据（密级、模型、业务类别）与动态交互组件（单选/多选/手写/二维码）的物理任务打印出来；人类离开电脑用手机扫码反馈，数据自动落库并驱动 ICS 消息总线唤醒 AI 开启下一轮。

## 🏷️ 页面元数据设计规范 (Metadata Architecture)

每一份由 AI 发起打印的物理纸张，顶部与底部均遵循严格的工业级版式规范：

### 1. 顶部页眉 (Header Bar)
* **密级标签 (Security Level)**：`[公开 / 内部 / 秘密 / 机密 / 绝密]`（根据密级动态上色：公开绿、内部黄、机密红）
* **发起 Agent (Agent ID)**：例如 `CodeArchitect`、`PlannerBot`
* **运行模型 (Model)**：例如 `deepseek-r1`、`gemini-3.7-flash`
* **业务类别 (Category)**：`[技术 / 业务 / 思考 / 私人 / 决策 / 告警]`
* **任务短码 (Short ID)**：例如 `#A8F9`（方便物理归档与口头索引）

### 2. 底部页脚 (Footer Bar)
* **页码指示**：`Page 1/1`
* **交互操作指引**：`📱 手机微信/相机扫码提交决策与批注`
* **专属高精二维码 (Dynamic QR Code)**：直接编码该任务专属的移动端交互链接。

---

## 📱 扫码后的移动端交互体验 (Mobile Web UX)

* **零摩擦打开**：手机扫码后在 Safari / 微信内秒级直达极简暗黑风格 H5。
* **信息全景卡片**：展示任务完整背景、AI 提出的核心问题或方案对比。
* **动态组件表单**：
  * **单选决策框 (Single Choice)**：`[ 批准路线 A ]` / `[ 驳回并修改 ]`
  * **多选偏好框 (Multi Choice)**
  * **随笔补充意见 (Text Comments)**
* **一键送达 AI**：点击提交后，屏幕展示微动效反馈，后台立即向 ICS 消息通道发送广播。

## 🖥️ 桌面端全量信息控制台 (`/dashboard`)

访问 `http://<HOST_IP>:3000/dashboard` 即可查阅：
* 历史所有被打印出去的物理任务全集；
* 人类扫码回复的明细、时间戳与设备指纹；
* 在线查看/下载已编译的高清 A4 PDF；
* 追踪任务流转状态（`PRINTED` $\to$ `READ` $\to$ `RESPONDED` $\to$ `ARCHIVED`）。

## 🚀 启动与运行

```bash
# 启动 ics-paper-hub 服务
./bin/ics-paper-hub --port 3000 --printer-ip 192.168.31.202
```

### AI 调用 API 示例 (创建物理交互任务)：
```bash
curl -X POST http://127.0.0.1:3000/api/tasks/create \
  -H "Content-Type: application/json" \
  -d '{
    "title": "2026年架构重构路线审批",
    "content": "请评估以下两种方案：\n方案A：纯本地自研Go单二进制\n方案B：引入第三方中间件",
    "security_level": "内部",
    "agent_id": "CodeArchitect",
    "model_name": "deepseek-r1",
    "category": "技术",
    "auto_print": true,
    "widgets": [
      {
        "id": "route_choice",
        "type": "SINGLE_CHOICE",
        "label": "请选择采纳的架构路线",
        "options": ["方案A (纯本地Go)", "方案B (第三方微服务)"]
      }
    ]
  }'
```
